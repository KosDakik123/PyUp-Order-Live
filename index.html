Order from the table. No app, no waiter pad.

Customers scan a QR code, browse the menu, and send the order straight to the shop. Owners manage stores, items, and incoming orders from the same site.

Menus

Each store gets a page for dine-in and takeaway, with photos, prices, and a cart.

QR tables

Print a code per table so the kitchen knows where the order came from.

Staff tools

Track open orders, finish them, and see how each store is doing.

How this site is hosted.

GitHub Pages serves these screens. Saving an account, a store, or an order still happens on the PyUp server. From this public site those requests go to the live server. On your own computer they go to http://127.0.0.1:8000.
